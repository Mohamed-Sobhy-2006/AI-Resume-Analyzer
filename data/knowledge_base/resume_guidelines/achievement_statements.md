# Achievement Statements
Achievement statements show impact instead of listing duties.
- Start each bullet with a strong action verb such as Built, Designed, Improved or Automated.
- Add numbers: percentages, time saved, users, or dataset size.
- Use the pattern: action + what you did + measurable result.
- Example: Reduced report preparation time by 40% by automating data cleaning with Python.
- Avoid vague phrases such as responsible for or worked on.
