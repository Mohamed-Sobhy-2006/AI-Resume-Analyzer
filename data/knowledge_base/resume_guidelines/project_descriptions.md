# Project Descriptions
Projects are the strongest evidence for students and career changers.
- Give each project a name, a one-line purpose and the technologies used.
- Explain your personal contribution and the problem it solves.
- Include results, such as accuracy achieved, number of users or response time.
- Add a GitHub link with a README that explains how to run the project.
- Prefer 2-4 strong projects over many small ones.
