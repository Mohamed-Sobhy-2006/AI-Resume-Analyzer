# AI Engineer Roadmap
An AI Engineer builds applications that use machine learning models and large language models in production.
Stage 1 (months 1-2): Learn Python, Git and SQL fundamentals.
Stage 2 (months 3-4): Learn machine learning basics with scikit-learn and deep learning basics with PyTorch.
Stage 3 (months 5-6): Learn NLP, embeddings, LLMs, prompt engineering and retrieval-augmented generation (RAG).
Stage 4 (months 7-8): Build and deploy APIs with FastAPI and Docker; learn a cloud platform.
Stage 5 (months 9-10): Publish 2-3 AI portfolio projects such as a RAG chatbot, and prepare for interviews.
