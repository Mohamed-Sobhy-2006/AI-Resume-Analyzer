# Data Scientist Roadmap
A Data Scientist uses statistics and machine learning to answer business questions.
Stage 1 (months 1-2): Learn Python, SQL and descriptive statistics.
Stage 2 (months 3-4): Learn data cleaning and visualization with Pandas, Matplotlib and Seaborn.
Stage 3 (months 5-6): Learn probability, hypothesis testing, regression and classification with scikit-learn.
Stage 4 (months 7-8): Complete real datasets on Kaggle and practice communicating results.
Stage 5 (months 9-10): Learn basic deployment and build a portfolio of 3 end-to-end analyses.
