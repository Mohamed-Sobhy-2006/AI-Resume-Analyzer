# Backend Developer Roadmap
A Backend Developer builds the server-side logic, databases and APIs of applications.
Stage 1 (months 1-2): Learn Python, Git and command-line basics.
Stage 2 (months 3-4): Learn SQL, database design and an ORM such as SQLAlchemy.
Stage 3 (months 5-6): Learn REST API design with FastAPI, authentication with JWT and automated testing with pytest.
Stage 4 (months 7-8): Learn Docker, Linux basics and CI/CD pipelines.
Stage 5 (months 9-10): Deploy an API to a cloud provider and add it to your portfolio with documentation.
