# Data Analyst Roadmap
A Data Analyst collects, cleans and visualizes data to support business decisions.
Stage 1 (months 1-2): Learn Excel and basic statistics.
Stage 2 (months 3-4): Learn SQL: joins, aggregations and window functions.
Stage 3 (months 5-6): Learn a dashboard tool such as Power BI or Tableau.
Stage 4 (months 7-8): Learn Python with Pandas for cleaning and analysis.
Stage 5 (months 9-10): Build 3 portfolio dashboards, each with a business question and recommendation.
