# FastAPI
FastAPI is a modern Python web framework for building REST APIs. It uses type hints and Pydantic for automatic request validation and generates interactive documentation at /docs.
Key topics to learn: path and query parameters, request bodies with Pydantic models, dependency injection, authentication with JWT, SQLAlchemy database integration, background tasks, and testing with TestClient.
Backend and AI engineer job posts often list FastAPI for serving machine learning models and RAG applications.
