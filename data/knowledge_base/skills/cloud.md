# Cloud
Cloud computing provides servers, storage, databases and AI services over the internet. The main providers are AWS, Microsoft Azure and Google Cloud.
Key topics to learn: virtual machines, object storage, managed databases, IAM permissions, serverless functions, container services, and cost management.
Beginner path: learn cloud fundamentals, deploy a small API to one provider, and earn an entry-level certification such as AWS Certified Cloud Practitioner or Microsoft Azure Fundamentals (AZ-900).
