# NLP (Natural Language Processing)
NLP is the field of AI that helps computers understand and generate human language.
Key topics to learn: tokenization, stemming and lemmatization, TF-IDF, word embeddings, sequence models, transformers, named entity recognition, text classification, and large language models (LLMs).
Recommended tools: spaCy, NLTK and the Hugging Face Transformers library. NLP engineers also need retrieval-augmented generation (RAG), embeddings and vector search skills.
