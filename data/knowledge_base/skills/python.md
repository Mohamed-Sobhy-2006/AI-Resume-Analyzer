# Python
Python is a general-purpose programming language used for backend development, data science, machine learning and automation. Its readable syntax makes it the most common first language for AI careers.
Key topics to learn: variables and data types, functions, classes and modules, virtual environments, file handling, exceptions, list comprehensions, and testing with pytest.
Related libraries: Pandas and NumPy for data, scikit-learn for machine learning, FastAPI and Flask for web APIs.
Employers expect candidates to show Python through projects on GitHub, not only through course certificates.
