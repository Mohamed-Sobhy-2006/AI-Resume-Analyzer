# SQL
SQL (Structured Query Language) is used to store, query and analyse data in relational databases such as PostgreSQL, MySQL and SQLite.
Key topics to learn: SELECT, WHERE, ORDER BY, JOIN, GROUP BY, HAVING, subqueries, window functions, indexes, and database design with primary and foreign keys.
SQL is required for almost every data analyst, data scientist and backend developer job. Practice by writing queries on a real dataset and describing the business question each query answers.
