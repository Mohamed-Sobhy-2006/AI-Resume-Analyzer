# Machine Learning
Machine Learning teaches computers to find patterns in data and make predictions without explicit rules.
Key topics to learn: supervised and unsupervised learning, regression, classification, clustering, train and test splits, cross-validation, overfitting, feature engineering, and evaluation metrics such as accuracy, precision, recall and F1 score.
Recommended tools: scikit-learn, Pandas, NumPy and Jupyter notebooks. Build two or three end-to-end projects, from data cleaning to a deployed model, to prove the skill.
